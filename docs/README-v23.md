# English God Quiz v23

## 基準
動作基準は v20-8。v21/v22 の機能をデータ削除なしで差分移植。

## 引き継ぎ
- 語族・派生語データを全難易度で利用可能
- 派生語4択は同品詞を優先
- 文脈・類義語・派生語も基礎・標準から選択可能
- 全語彙に品詞表示（派生語問題では非表示）
- 例文・例文和訳を維持
- タグ検索を除外
- 回答後まで無効な「次の問題」を常時表示
- スマホ版に進捗リセット
- 問題データの重複整理による削除は実施しない

## 安全方針
v22-1 のような語彙削除による起動不能を再発させないため、重複は出題候補の選択時に排除し、元データは保持する。
